# Hush design system

## Direction

Use the blue-black, blue/lavender light, fine borders and quiet typography from `ui-concept.png`. Keep the Hush brand and English copy. The existing live particle renderer remains the visual system. Completion shows independent session metrics without changing the renderer or primary navigation. Procedural blue/lavender nebula wisps and dark dust add depth to the shared galaxy without image assets.

## Tokens

`HushTheme` always uses the dark Material scheme; system wallpaper colors and light mode do not override it. `HushColors` defines semantic background, surface, raised surface, text, muted text, accent/on-accent, border, error and success colors, plus the renderer/chart palette. Use semantic roles rather than new hex values in screens.

Typography uses the system sans-serif: Light titles/countdown, Regular body and Medium actions. Sizes are 12/14/16/22/28/48sp with explicit line heights. Avoid wide body-text tracking and preserve user font scaling.

`HushSpace` provides 4/8/12/16/24/32dp spacing and a 640dp content width. `HushShapes` provides 24dp panels, 12dp controls and capsule actions. `HushMotion.TransitionMillis` is 250ms for content transitions; the existing particle smoothing has separate physiological/visual responsibilities.

## Components and routes

- `HushPanel`: translucent dark surface, thin border, consistent padding and animated content size.
- `PrimaryAction`: full-width capsule with a minimum 52dp height. Icon controls retain a minimum 48dp touch target.
- Home: brand/device status, a width-responsive square galaxy area capped at 440dp high, and a compact preparation panel. All galaxy views use a radius of 43% of the canvas's smaller dimension; the subtitle and panel spacing are reduced while action touch targets remain unchanged. The page scrolls on constrained screens. Start is gated by a real connection or a usable simulation.
- Device sheet: permission, Bluetooth, connection state, device selection, disconnect and simulation. No raw packet counters in the user flow.
- Preparation panel: a clock icon and `Guided Meditation` label sit above a large inline `10:00` minute wheel and `A quiet space for a brighter you.` subtitle. The wheel supports 1-60 minutes, defaults to 10 minutes, and shows stacked up/down chevrons. The heading and subtitle are centered; the time and chevrons form one centered group with a 12dp gap that scales its text width with the font size. Scrolling applies the centered value immediately with momentum and snapping, without presets or a dialog. Simulation resets the visible wheel to 10 minutes and disables scrolling. The primary capsule action includes a right arrow; the quiet connection status below it opens the device sheet, retaining access to simulation and device controls.
- Soundscape sheet: the Home header's upper-right music-note button replaces its former Muse button and opens Rain, Ocean, and Fireplace selection and preview in a scrollable list. Its accessibility label includes the selected track. Rain is the default. Dismissal, backgrounding and session start stop preview audio. Preserve the existing panel style and English labels.
- Session: remaining time, circular Pause/Resume, an upper-right music-note button and confirmed Finish. The music button opens the shared Soundscapes sheet with Rain, Ocean, Fireplace and volume. Selecting a track switches service-owned playback immediately, preserving pause and volume; there is no separate preview during a session. The control region follows the reference layout: remaining time and its caption, a transparent 56dp circular Pause/Resume control with a fine lavender outline, the retained Finish action, then a borderless 64dp Calmness curve at the bottom. The live curve omits its heading, axes, grid lines, and empty-data text; its accessibility description and recorded gaps are retained. Completion uses the single-metric Calmness Replay chart. Landscape uses the right control column and constrained controls scroll. Trusted EEG can provide Calmness from the first second. Missing or rejected EEG keeps the previous visual parameters, opacity, and rotation speed, without a data-gap or quality notice. Before the first trusted value, rotation is decorative. A real disconnect freezes the galaxy and shows `Reconnecting…`; `Paused` retains its own state. Pause stops motion. Signal processing still rejects untrusted EEG, and chart gaps remain missing data; retained visuals never create Calmness measurements.
- Completion: `Finished` shows the session galaxy and a full-session Calmness Replay panel. It reuses History playback, seeking, zoom and pan with only Calmness visible and no metric checkboxes. Entering completion starts 30x playback once, including while the initial results sheet is open; the selected sample drives the galaxy just as in History. Seeking pauses playback; missing Calmness stays unavailable while the galaxy retains its prior appearance. A bottom sheet opens once per session with the actual `Total Time` label and duration centered above three cards (`Calm`, `Stability`, `Heart Rate`). Calm and Stability use 0-100; Each metric title and value group is centered within its column. Heart Rate shows its integer and `BPM` side by side in one centered row. There is no overall grade. Unavailable metrics display `—`. `More Details` waits for saved history to load. Swipe, scrim tap or Back dismisses the sheet; `Results` reopens it. Back with the sheet closed returns Home. Returning from details and configuration changes preserve dismissal. Completion uses the shared galaxy panel with a height limit of 34% of the available page height, clamped to 120-440dp, with a scrollable Calmness Replay panel below it. The Replay panel uses the same full-width spacing and drawing height as History. History detail retains the width-responsive panel capped at 440dp high. Sheet content scrolls on constrained screens and respects system insets.
- History/detail: each card groups its original date and local start time (`HH:mm`, 24-hour) on the first text row, with session duration and track on the next row, with a right-aligned `Calm` label and rounded 0-100 score. Missing scores show `—` under the same 30-measured-second rule as details. The text column wraps on narrow screens and with larger fonts. Saved sessions and particle replay use one combined six-metric Replay chart instead of separate Calmness and relative-trend plots. History cards support swiping from end to start to reveal `Delete` and open a confirmation dialog; canceling restores the card. The same action is available to accessibility services. The two checked-in original sessions remain deletable but reappear after a cold app restart; other deletions remain permanent. Small history star emblems are decorative session identifiers, not physiological measurements; the detail visualization uses recorded samples. Session details uses 4dp of top content padding below its app bar and starts with a centered small-text row showing the session date, local start time (`HH:mm`), and actual duration (`MM:SS`), separated by middle dots. A compact three-column metric panel sits 8dp below this row, followed by the galaxy visualization. Each metric label and value group is centered, with thin vertical separators between columns and a horizontal heart-rate number/BPM pair. The metadata row wraps for larger fonts; there is no large-duration header. Total Time remains in the completion summary only, and elapsed time appears beside the Relative level label in the combined Replay chart. A lavender vertical cursor with a circular handle can be dragged horizontally or repositioned by tapping the plot, updating the selected time and galaxy replay. There is no separate replay slider. Accessibility services can adjust the cursor. Recorded gaps remain missing data during replay, while the galaxy continues rotating with retained appearance and no Data gap overlay. History samples do not record Bluetooth connection state, so replay does not infer a disconnect from a gap.

Page app bars use a left-arrow icon with a 48dp touch target and a `Back` accessibility label. Reusable controls live in `HushComponents`. Route composition is in `HushApp`; charts and particle summaries are in `SessionVisuals`. Activity code coordinates permissions, idle connection, service events and storage. Do not introduce signal processing into composables or let a hidden Home route claim a service-owned Muse.

## Accessibility and layout

Use safe system insets, bounded content widths, scrollable content, semantic names for icon controls/switches/sliders, and text labels for device/signal state. Do not rely on color alone. Validate portrait, landscape and enlarged text on actual rendered screens. No additional fonts, image assets or UI libraries are required.

## Limits

Calmness uses a fixed public resting reference: 50 is the typical CogWear resting feature level before temporal smoothing. It does not confirm a calm mental state. Calmness and Stability are demo heuristics, not validated meditation-quality measurements or medical interpretations; Heart Rate is an experimental PPG estimate requiring physical-device validation. Stability reflects head stillness. Details show the same three metrics without an additional notice below the summary. Each requires 30 valid measured seconds independently. Live and completion Calmness charts use stored 0-1 values on a fixed 0-100 axis with a lavender stroke. Completion uses the same Calmness scale in its Replay panel; History uses the combined relative-scale chart described below. All charts use elapsed-time coordinates, isolated points, and visually distinct dashed bridges across gaps. Only the current database schema version 5 is supported, without automatic migration or history reset. Loading the bundled simulation does not add history; a new simulation saves an ordinary dated session using the second-earliest recording's measured heart rate and original signal gaps. Missing values remain unavailable, and the same 30-measured-second threshold applies. Ordinary history deletions are permanent; the two project-bundled snapshots are restored after a cold app restart. Device addresses remain local preferences. Frame-rate and Bluetooth reliability claims require measurement on a physical target device.

All main particle views use `GalaxyParticleField`, `GalaxyNebula`, and their fixed seed, palette, glow, and trails. Home and live meditation share motion state with the frozen completion Mindprint; recorded detail frames use the same renderer. The renderer is implemented with Compose Canvas and procedural 2D drawing.

For samples with recorded Calmness, visual agitation follows `u * (0.5 + 0.5 * u)`, where `u = 1 - calmness`: a 50-point score yields 0.375 agitation, keeping typical resting and calmer states cohesive with shorter trails and smaller particle displacement. Live rotation ranges from 0.06 to 0.23 radians per second, preserving the maximum while slowing settled drift. Visual smoothing remains unchanged; missing intervals hold the last appearance and rotation speed without producing new measurements. Detail replay initializes its phase from the selected elapsed time and rotates continuously at the selected sample speed; gaps retain the last trusted sample at or before the selected time. Completed Mindprints remain frozen until replay starts. Only measured Calmness drives agitation; absent scores never fall back to EEG bands.

Charts round consecutive sample connections with cubic curves using horizontal endpoint tangents. Curves pass through every recorded value and remain between adjacent values; smoothing affects drawing only, never processing or scores. Invalid samples and nonconsecutive seconds split the measured solid curve; a subdued dashed cubic bridge links the surrounding trusted points. A trailing gap holds the last trusted level with a dashed line, and updates when a new trusted point arrives. No line is drawn before the first trusted point. Isolated samples remain visible as dots; continuous curves do not add a dot at every second.

Calmness charts use a 2dp stroke and 2dp isolated-point radius to keep short trusted segments visible. Missing intervals use subdued dashed bridges instead of measured solid strokes; missing values never create chart measurements.

## Combined history replay chart

History details show Calmness, Alpha, Theta, Beta, Heart Rate, and Stability in a single Replay panel. Color-coded checkbox controls sit below the chart and time-axis labels in two equal-column rows: Calmness, Stability, Heart Rate first; Alpha, Theta, Beta second. Compact 16dp checkbox visuals stay inline with single-line metric labels; labels truncate on narrow screens or with larger fonts, while semantics retain their full names. Each option retains a 48dp touch height. All controls default to selected. Visibility survives configuration restoration for the current session and resets when a different session opens. All controls can be unchecked without disabling time selection. The live chart stays borderless; completion reuses this panel with only Calmness and no metric controls.

The fixed Relative level axis spans 0-100. Stored Calmness, head stillness, and relative EEG bands are multiplied by 100; Heart Rate maps 40-180 BPM linearly to 0-100. This mapping affects drawing only. Cursor labels show integer Calmness/Stability, one-decimal relative EEG levels, and actual integer BPM. They use the shared three-second visual average at the selected recorded second, never retained values from missing seconds. Missing selected measurements have no visible label or intersection marker; their unavailable values remain in accessibility descriptions. History details show data coverage below the Replay panel. Each signal is validated independently; absent EEG does not hide usable motion or heart rate.

Measured intersections have colored dots on the smoothed curves; matching values appear below the metric names in the legend. The plot canvas reserves at least 304dp plus the upper scale-label space, increases with font scale, and expands to fit all measured label heights. Color, names, checkbox semantics, and accessible selected-time/value descriptions support identification. Tapping, dragging the cursor handle, and accessibility seeking use the existing shared replay cursor and update the galaxy from the same sample.
The history Replay plot supports two-finger time-axis zoom from the whole session to 10x (at least one second visible) and two-finger horizontal panning within the session. The pinch midpoint stays anchored; vertical scaling remains fixed at 0-100. Single-finger horizontal drags pan the visible time range. Taps and horizontal drags starting within the cursor handle's 48dp touch target seek instead; vertical swipes remain available for page scrolling. Pinching, panning, and releasing the remaining finger do not seek. Time-axis endpoints follow the viewport; a selected cursor outside it is hidden without changing the selected sample. Zoom survives configuration restoration and resets for another session. Accessibility actions provide Zoom in, Zoom out, and Reset zoom; accessibility seeking brings the requested time into view.
The history Replay panel uses the full safe viewport width with 4dp outer and 8dp inner horizontal spacing, including in landscape. Metadata, score summaries, and galaxy retain their centered 640dp content limit and original horizontal spacing. Other Hush panels keep their default padding. The 100 and 0 scale labels sit above their horizontal grid lines at the left edge of the plot, without a separate axis column. The upper label has font-scaled vertical space so it remains fully visible.
The Replay heading, Relative level label, selected time, compact 16dp Play/Pause icon with a 48dp touch target, and fixed `30×` speed share one header row. The relative-scale label truncates on constrained layouts rather than wrapping the controls. Each entry into history details automatically starts playback once usable samples have loaded, advances the shared recorded-sample cursor at 30 recorded seconds per real second, and keeps the current time in the visible window. Pause preserves the selected time; reaching the last recorded second pauses automatically, and Play at the end restarts from the first recorded sample. Tapping or dragging the cursor and accessibility seeking pause playback. Empty or single-sample recordings disable Play. Leaving the chart, backgrounding the app, or recreating its UI stops playback; visibility and zoom restoration remain unchanged. Playback changes neither recordings nor audio.
Autoplay runs once per page entry and does not override a manual pause, restart after scrolling the chart offscreen and back, or resume after backgrounding or configuration restoration. Opening the detail page again starts playback at the selected time (or the first sample if already at the end).

The Replay panel has 4dp vertical padding, 2dp gaps between chart sections, a smaller heading, and compact inline two-row legends. Space removed from panel padding and controls is assigned to the taller curve area, without shrinking touch targets or changing playback and gestures.

Replay curves, cursor metric dots, legend values, and accessibility values share a centered three-second visual average (previous, current, next recorded second). Averages stay within consecutive measured runs; missing seconds remain missing and use dashed guides. The spline passes through each averaged second, placing cursor dots on the curve. This changes presentation only, not stored samples, scoring, or galaxy replay.

All metrics use their own color at 55% opacity for dashed gap bridges and trailing guides. The Replay panel explains “Dashed lines: no measured data”. These guides have no marker or numerical value and never enter calculations. Internal bridges use a cubic Bezier with horizontal endpoint tangents; trailing guides are horizontal. They do not extrapolate measured trends.

Live Calmness shows a compact heading, current smoothed value and point, and a subdued 50 resting-reference line. Missing current values show — and no endpoint marker. There are no invented 15/85 thresholds. Completion/results and details show measured data coverage per metric. Help explains all six metrics, gap guides, smoothing, replay, coverage and experimental interpretation.

Live meditation controls are ordered as Calmness chart, remaining time, Pause/Resume and Finish. The chart has 100/50/0 axis labels and a larger right-aligned current value, without a help icon or reference caption. Help is available only in the Home and History headers. Existing dark blue/lavender colors remain unchanged.

Coverage uses separate raised cards with a prominent one-decimal percentage, progress bar, measured/total MM:SS durations and a textual availability status. Exact coverage below 50% uses Error (red), 50% to below 70% uses Warm (yellow), and 70% or above uses Accent. These thresholds describe data availability only and do not change score computation. Coverage contains no help button.

Session details keeps only Calm/Stability/Heart Rate summary values above the galaxy. Data coverage is a separate panel below the Replay chart and metric controls, so it does not push the visualization and curves below a large coverage block.
